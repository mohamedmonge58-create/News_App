## ✨ Features

- Browse news articles by category.
- Fetch news using REST APIs.
- Search for news articles.
- View article details and access the full article.
- Switch between Arabic and English.
- Support for light and dark themes.
- Save language preferences locally.
- Responsive user interface built with Flutter.

## 🛠️ Technologies

- Flutter
- Dart
- REST APIs
- Provider
- SharedPreferences
- Flutter Localization
- url_launcher

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/mohamedmonge58-create/News_App.git
   ```

2. Navigate to the project directory:

   ```bash
   cd News_App
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Generate localization files:

   ```bash
   flutter gen-l10n
   ```

5. Run the app:

   ```bash
   flutter run
   ```

## 🌐 Localization

The application supports English and Arabic, allowing users to change the display language through the app settings.

## 🎨 Themes

Users can switch between light and dark themes.
